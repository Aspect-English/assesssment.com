V5.3.4 Speaking Phase Cues

新增：
- Direction 播完、準備倒數前：語音 + 畫面顯示「Begin preparing now」
- 準備/題目播放流程完成、正式錄音前：語音 + 畫面顯示「Begin speaking now」
- 「Begin speaking now」播完後才播放較高音 Beep，接著開始錄音與 Response Time
- Practice Question 也加入相同提示，讓學生先熟悉正式流程
- 移除 Preparation 結束時額外的一次 beep，避免正式作答前出現雙 beep

流程：
Direction → Begin preparing now → Preparation Time
→（題型需要時播放題目/等待）
→ Begin speaking now → Beep → Recording / Response Time
