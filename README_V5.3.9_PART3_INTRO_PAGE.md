# V5.3.9 — Part 3 題組說明頁

學生端流程：
Part 3 Direction
→ 題組說明頁（只顯示 Situation / Passage）
→ Q5
→ Q6
→ Q7

題組說明頁：
- 不顯示 Q5/Q6/Q7
- 不顯示 Preparation Time
- 不顯示 Response Time
- 預設顯示 10 秒
- 老師後台可設定顯示秒數
- 時間到自動進入 Q5

Q5/Q6/Q7：
- Q5 預設 3 秒準備 / 15 秒回答
- Q6 預設 3 / 15
- Q7 預設 3 / 30
- 後面的問題不會提前顯示

老師後台：
新增題目 → Speaking → Respond to Questions
→ Part 3 題組快速新增
→ 填共用 Situation / Passage
→ 設定「題組說明頁顯示時間」
→ 填 Q5/Q6/Q7
→ 一次建立 Q5–Q7

注意：建立後仍需到測驗組卷把 Q5、Q6、Q7 依序加入測驗。
